# 批量打包 C4D 工程

*Batch Pack C4D Projects · Cinema 4D script plugin · Save Project with Assets · collect textures and assets for .c4d files*

Cinema 4D 里的一个小脚本插件：选中一个文件夹，把里面多个 `.c4d` 工程一次性打包成「各自独立、带贴图素材」的文件夹，方便归档和交付给别人。

> 它不是独立软件，要在 C4D 里面运行；不用安装任何额外的库。

## 能做什么

- **批量打包**：一个文件夹里的所有 `.c4d` 工程逐个处理，每个工程生成一个同名文件夹（里面含工程文件和贴图等资源）
- **想打包哪几个就勾哪几个**：刷新列表后可勾选，支持全选 / 全不选、点整行、Shift + 点击区间连选
- **自然排序**：1、2、…9、10、11，不会排成 1、10、11、2
- **实时进度**：显示「加载 / 打包 / 统计」、第几个 / 共几个 / 百分比 / 当前文件名；可点「本工程完成后停止」
- **缺失资源报告**：结束后把找不到的贴图按工程分组列出，并保存 `打包报告.txt` 到原文件夹
- **失败保护**：打包失败的半成品文件夹自动改名加「-打包失败」后缀，只改名不删除，方便人工检查
- **空壳检测**：源工程很大但打包结果异常小时，判定失败并标记，避免误以为成功
- **不覆盖**：目标文件夹已存在就自动加数字后缀（如 `工程-1`），绝不动你原来的文件

## 怎么用（3 步）

1. 把 `自动打包插件.py` 和 `自动打包插件.tif` 两个文件一起放进 C4D 安装目录下的 `library\scripts` 里（可以单独建一个 `自动打包插件` 文件夹），重启 C4D 后，在脚本菜单里就能看到带图标的插件，点它运行。
   - 例：`C:\C4D 2024.4.0\library\scripts\自动打包插件\`，把版本号换成你自己的。
   - 同名的 `.tif` 就是菜单图标，和 `.py` 放在同一个文件夹才会显示；临时试用也可以只在「脚本 → 脚本管理器」里载入 `.py` 运行，这种方式没有图标。
2. 点「运行」，在弹窗里选一个放着 `.c4d` 工程的文件夹，点「刷新列表」，勾选要打包的工程。
   - 不刷新直接点「确定」= 打包整个文件夹里的全部 `.c4d` 工程。
3. 点「确定」，等进度窗口跑完，看结果弹窗；如果有缺失贴图，去原文件夹里看 `打包报告.txt`。

## 使用前请留意

- 建议先拿两三个不重要的工程试一遍，确认你的 C4D 版本能正常打包，再处理正式文件。
- 打包会在原文件夹里新建文件夹，不会删除或覆盖原文件；但重要工程还是先备份一份更稳妥。
- 打包依赖 C4D 自带的「保存工程并收集资源」功能；第三方插件生成的特殊素材，C4D 可能识别不到，请以 `打包报告.txt` 为准。
- 结果是按工程分开的文件夹，不会自动压缩成 zip。

## 运行环境

- 已在 Cinema 4D 2024.4 上实际使用；代码里兼容 C4D 内置的 Python 2 / Python 3，也针对不同版本的界面接口做了兜底，老版本（R20 起）应该也能用，但请先用不重要的工程试一遍
- 只依赖 C4D 自带的 `c4d` 模块，不需要 pip 安装任何东西
- 界面文字目前为中文
